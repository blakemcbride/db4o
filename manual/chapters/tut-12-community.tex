That's it for the tutorial and you now can go wild with db4o.

The original db4o community website, forums, blogs and bug tracker no longer exist. db4o is now maintained at \href{https://github.com/blakemcbride/db4o}{\nolinkurl{github.com/blakemcbride/db4o}}. There you can find the source code, the build instructions and this manual.

\section{Report Bugs}
\label{tut:db4ocommunity:bugrepors}

Software contains bugs and so does db4o. If you find a bug, please report it, or send a fix, through the \href{https://github.com/blakemcbride/db4o}{GitHub repository}.

When possible include a small test program which reproduces the issue. A test case avoids confusion and effort to reproduce the bug.
