\chapter{Getting Started}
\label{drs:db4o-replication-system-drs-getting-started}

This topic will give you some initial information about dRS and will help to get your environment ready to work with dRS.

\section*{Download Content}

The distribution comes as a zip archive. Extract the content to any folder before you start to use the dRS. You can find the offline version the documentation in the\textbf{/docs/reference} folder. The API documentation in located in \textbf{/docs/api} folder.

\section*{Requirements}

The dRS version corresponds to the db4o version. Ensure that the db4o and the dRS version are the same.

The dRS system depends on the JDK 5 version of db4o and therefore requires Java 5 or newer.

In order to use the \hyperref[drs:db4o-replication-system-drs-replication-with-rdbms]{Hibernate-Replication} (p.~\pageref{drs:db4o-replication-system-drs-replication-with-rdbms}) functionality the Hibernate core version 3.1 is required. The Hibernate dependencies have been included in the lib folder of the dRS distribution for your convenience. When you require more complex Hibernate Mappings or what to benefit from additional Hibernate features, feel free to download the entire Hibernate-distribution on the \href{http://www.hibernate.org/}{Hibernate project website}.

To run the provided ant-scripts \href{http://ant.apache.org/}{Apache Ant 1.6} or later is required.

\section*{Installation}

The dRS functionality is delivered in a single jar file. If you add dRS-8.1-core.jar to your CLASSPATH, dRS is installed. For using db4o replication to another database (RDBMS) you will also need the Hibernate library, which is included in the /lib folder in the distribution.

Here is how to add the dRS library to an Eclipse project

\begin{itemize}
\item Create a folder named "lib" under your project directory, if it doesn't exist yet
\item Copy dRS-8.1-core.jar to this folder
\item Right-click on your project in the Package Explorer and choose "refresh"
\item Right-click on your project in the Package Explorer again and choose "properties"
\item Select "Java Build Path" in the tree view on the left
\item Select the "Libraries" tab page.
\item Click "Add Jar"
\item The "lib" folder should appear below your project
\item Choose dRS-8.1-core.jar in this folder
\item Hit "OK" twice
\item You might need to repeat the same for hibernate3.jar
\end{itemize}
